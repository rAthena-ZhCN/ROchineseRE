/savechat：保存聊天窗口的内容
#
按住 ctrl 键并按 * 键，可在不透明和半透明之间切换小地图
#
按住 shift 键并用鼠标右键拖动可调整视角。要恢复原始角度，请按住 shift 键并双击鼠标右键
#
按住 ctrl 键并用鼠标右键拖动可放大和缩小。要恢复原始缩放，请按住 ctrl 键并双击鼠标右键。也可以使用鼠标滚轮放大和缩小
#
当鼠标光标移到怪物上时，它会变成一把剑，此时就可以攻击
#
击杀怪物获得的经验值与对其造成的伤害成正比。*当多名玩家攻击同一只怪物时，先发起攻击的玩家将获得更多经验值
#
按住 ctrl 键并攻击怪物可进入锁定攻击状态，该状态会自动攻击目标直到怪物被击杀。要取消自动攻击，只需点击其他任意位置
#
[Left click] 地面上的物品即可将其拾取。拾取的物品会显示在物品栏中
#
[Right click] 物品可查看该物品的说明
#
脚下的两条横条是 HP 和 SP。绿色的是 HP，蓝色的是 SP。HP 降为 0 时玩家死亡。作为警告，当玩家 HP 处于或低于 25% 时，HP 条会变红
#
当 EXP 条满（100%）时，基础等级会提升，玩家将获得素质点，可自由投入到想要的属性中
#
当 EXP 条下方的 JOBEXP 条满（100%）时，职业等级会提升，玩家将获得技能点，可自由投入到想要的技能中
#
玩家站立不动时，HP 和 SP 会缓慢恢复。*坐下时恢复速度加倍。但是，当玩家负重超过 50% 时，HP 和 SP 无法自动恢复
#
负重：显示为当前负重和最大负重。玩家无法携带超过最大负重的物品。当负重超过最大负重的一半时，负重数值会变红，HP 和 SP 的自动恢复会停止。当负重超过最大负重的 90% 时，玩家将无法攻击或使用技能
#
Zeny：这是仙境传说 Online 中使用的货币。*玩家交易或购买物品时会自动扣除
#
基础等级提升时，玩家会获得素质点，可投入到自己的属性中
#
STR（力量）：直接影响玩家的攻击。力量越高，可携带的物品越多。增加力量会提升攻击
#
DEX（灵巧）：直接影响武器的使用。灵巧越高，武器的效率就越高。使用弓和箭时，增加 DEX 会提升攻击和命中；它还会影响施法速度
#
AGI（敏捷）：与玩家的敏捷直接相关。增加敏捷会提高闪避敌人攻击的几率；各种武器的攻击速度也会提升
#
VIT（体质）：与玩家的防御和 HP 直接相关。VIT 越高，防御越高，受到攻击时承受的伤害越少；它还会提高最大 HP 和 HP 恢复速度
#
INT（智力）：与玩家的 SP 直接相关。INT 越高，魔法攻击（MATK）和魔法防御（MDEF）越高
#
LUK（幸运）：幸运与多种事物直接相关，增加 LUK 主要影响暴击几率以及幸运闪避（纯靠运气闪避敌人攻击）的概率
#
[Print Screen] 或 [Scroll Lock]：截图。截图会保存在 [ScreenShot] 文件夹中
#
[F10]：调整聊天窗口的大小
#
[F11]：仅保留基本信息窗口和聊天窗口；关闭所有其他窗口
#
[F12]：打开/关闭快捷键栏。*将常用物品或技能拖到 F1-F9 键上，然后按下对应按键即可快速使用
#
[INSERT]：坐下或站起 *等同于在聊天窗口中输入 [/sit] 或 [/stand]。坐着时 HP 和 SP 的恢复速度是站立时的两倍
#
[Alt] + [End]：开启/关闭角色下方的 [HP/SP] 条显示
#
[Alt] + [Home]：开启/关闭小地图上的可到达区域指示
#
[Alt] + [=]：在双字节和单字节输入之间切换输入状态。以双字节字符输入的命令将不会被执行；只有单字节命令会被执行
#
[Alt] + [F10]：开启/关闭聊天窗口
#
[Alt] + [1~9]、[Ctrl] + [-,=,w]：[Alt] + [1~9] 使用以下表情：感叹号、问号、音乐、爱心、汗、灯泡、愤怒、云、金钱、月食。[Ctrl] + [-,=,w]：剪刀、石头、布

/WHO：显示当前在线玩家数量
#
/WHERE：显示玩家当前位置和坐标
#
/H：显示基本命令的说明
#
/BGM：开启/关闭背景音乐。*也可以在窗口中按 [Alt] + [0] 完成
#
/SOUND：开启/关闭音效。*也可以在窗口中按 [Alt] + [0] 完成
#
/EFFECT：开启/关闭游戏中的各种图形特效。*关闭特效能让游戏运行更流畅
#
/SKIP：开启/关闭画面同步
#
/EX [角色名]：忽略该玩家发来的所有 1:1 聊天
/IN [角色名]：接受该玩家发来的 1:1 聊天
#
/EXALL：忽略任何玩家发来的所有对话
/INALL：接受任何玩家发来的对话
#
/EX：显示被忽略的玩家列表
#
/ORGANIZE [队伍名]：组建队伍。*队伍队长可以邀请其他玩家加入
#
右键单击你想邀请的玩家，选择“邀请加入队伍”即可邀请该玩家加入
#
/LEAVE：离开当前队伍。*使用此命令不会有额外确认
#
/EXPEL [角色名]：队伍队长可以将特定成员逐出队伍。*使用此命令不会有额外确认
#
点击聊天窗口右下角的 [circle]，选择“队伍频道”，即可使用队伍频道与队友聊天
#
%：在消息开头加上 % 即可直接在队伍频道聊天；或按住 ctrl 键后按回车，将消息直接发送给队友
#
右上角的小地图会显示所有队伍成员的位置
#
1:1 聊天：在聊天窗口左侧输入角色名，在右侧输入消息；使用 TAB 键可在两个输入框之间快速切换
#
小地图按键 [+/-] 可放大/缩小地图
#
[MVP 系统]：与 Boss 级怪物战斗时，为保护造成最多伤害的玩家的权益，Boss 的 MVP 物品会自动掉入 MVP 玩家的物品栏；如果 Boss 怪物没有掉落 MVP 物品，则补偿该玩家 50% 的经验值
#
在窗口模式下游戏窗口可以移动。按住 [Alt] + [Space] 并按 [m] 键，然后使用方向键或鼠标移动游戏窗口
#
/fog：开启/关闭雾效。雾效能更好地表现各种地图的天气。对于配置较低的电脑，这会增加运算负担。如果游戏卡顿或异常退出，建议玩家关闭雾效。雾效可以在 Config 中永久开启/关闭
#
从怪物身上获得的物品是未鉴定的；使用从工具店购买的放大镜来鉴定并确认物品的效果和用途
#
如果猎人想使用陷阱系列技能，必须携带 [Booby Trap] 道具
#
创建公会需要 1 个 Emperium；命令为 /GUILD [公会名]，名称不能包含特殊字符或空格。Alt + G 打开公会窗口
#
公会成员可以使用 /GC [消息] 或 $ [消息]，或按 Alt + Enter 进行公会聊天
#
要将卡片插入装备的插槽，请先卸下该物品，然后双击卡片。此时会显示可用于该卡片的物品列表供选择
#
礼仪点数系统说明
--新手可从基础技能等级 8 开始使用
--右键单击玩家并选择给予礼仪点数
#
部分异常状态说明
--眩晕：眩晕时玩家无法移动
--黑暗：画面变暗；对怪物而言，这意味着视野范围缩小
--冰冻：无法移动；只有在受到攻击时才会恢复
#
死亡时会扣除经验值。使用技能或进行战斗后，必须经过 5 秒延迟才能下线
#
向卡普拉职员查询，以使用仓库、存档点和租用手推车。

#
跟随他人功能：点击 [Shift] + [right click]
#
[Alt] + [L]：用于表情栏，点击 Alt+M 或 Alt+L 选择你想要的表情。
